# IPL Data Analysis using Microsoft Excel

## Project Overview
This project analyzes IPL match and player performance data using Microsoft Excel.

## Objectives
- Analyze team performance
- Identify top run scorers and wicket takers
- Compare season-wise statistics
- Generate insights using visualizations

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Dashboards

## Key Insights
- Identified top-performing teams across seasons
- Analyzed player performance trends
- Compared batting and bowling statistics
- Created interactive dashboards for reporting

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Data Visualization
- Reporting
- Business Insights
